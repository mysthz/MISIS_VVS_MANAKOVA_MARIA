# Maze Adventure

## Описание проекта

**Maze Adventure** — консольная RPG-игра на Python, в которой игрок исследует лабиринт, взаимодействует с комнатами, собирает предметы, сражается с монстрами и пытается найти выход.

Главная цель игры — исследовать лабиринт, найти ключ и добраться до выхода, сохранив здоровье персонажа.

## Игровой процесс

В начале игры игрок появляется в стартовой комнате лабиринта. Перемещаясь между комнатами, он может столкнуться с различными событиями:

- **Пустая комната (Empty)** — безопасное место, в котором ничего не происходит.
- **Ловушка (Trap)** — наносит игроку 15 единиц урона. Каждая ловушка срабатывает только один раз.
- **Монстр (Monster)** — противник, с которым можно сражаться или от которого можно сбежать. Для атаки необходимо иметь оружие. Монстр обладает 30 единицами здоровья, а каждая успешная атака игрока наносит ему 10 единиц урона.
- **Сундук (Chest)** — автоматически открывается при посещении комнаты. Внутри может находиться оружие, броня, зелье здоровья или ничего. Каждый сундук можно открыть только один раз.
- **Портал (Portal)** — телепортирует игрока в случайную комнату лабиринта. Если игрок попадает в другую комнату с порталом, телепортация запускается повторно.
- **Ключ (Key)** — необходим для открытия выхода из лабиринта.
- **Выход (Exit)** — конечная точка игры. Для победы необходимо найти ключ.

Посещённые комнаты отмечаются на карте, что позволяет отслеживать исследованные участки лабиринта.

## Персонаж

У игрока есть:

- **Здоровье (HP)** — изначально 100 единиц. При снижении здоровья до нуля игрок погибает, и игра завершается.
- **Инвентарь** — список собранных предметов.
- **Ключ** — специальный предмет, необходимый для завершения игры.
- **Координаты** — определяют положение игрока в лабиринте.
- **Посещённые комнаты** — позволяют отслеживать исследованные клетки.

## Инвентарь и предметы

В игре предусмотрены следующие предметы:

- **Weapon** — оружие, необходимое для атаки монстра. Без него игрок не может сражаться.
- **Armor** — броня, уменьшающая получаемый от монстра урон с 30 до 15 единиц.
- **Potion** — зелье, восстанавливающее 30 единиц здоровья. Максимальное здоровье игрока — 100 HP.

Предметы автоматически добавляются в инвентарь при открытии сундука. Игрок может просматривать содержимое инвентаря и использовать зелья во время исследования лабиринта.

Оружие и броня остаются в инвентаре после использования.

## Управление

| Команда | Действие |
| --- | --- |
| `up` | Перемещение вверх |
| `down` | Перемещение вниз |
| `left` | Перемещение влево |
| `right` | Перемещение вправо |
| `inventory` | Просмотр инвентаря |
| `health` | Просмотр текущего здоровья |
| `use potion` | Использование зелья здоровья |
| `attack` | Атака монстра |
| `run` | Побег от монстра |
| `help` | Просмотр доступных команд |

Команды `attack` и `run` используются во время встречи с монстром. Для атаки необходимо иметь оружие.

## Условия победы и поражения

**Победа:** игрок находит ключ, добирается до выхода и успешно покидает лабиринт.

**Поражение:** здоровье игрока опускается до нуля. После смерти игра завершается.

## Структура проекта

- `main.py` — основной игровой цикл, обработка команд и взаимодействие игровых объектов.
- `maze.py` — создание лабиринта, перемещение игрока и отображение карты.
- `player.py` — класс игрока, управление здоровьем, лечением и состоянием персонажа.
- `rooms.py` — классы комнат, ловушек, монстров, сундуков и порталов.
- `inventory.py` — управление инвентарём игрока.

## Запуск игры

Для запуска необходимо выполнить файл `main.py`:

```bash
python main.py
```
